# Parquímetro 🚗

Projeto desenvolvido como atividade acadêmica com o objetivo de simular o funcionamento de um parquímetro, aplicando conceitos de lógica de programação e manipulação do DOM com JavaScript.

## 📋 Sobre o Projeto

A aplicação permite que o usuário informe um valor para estacionamento e, com base na quantia inserida, calcula automaticamente o tempo correspondente e exibe as informações na tela.

O projeto foi desenvolvido para praticar validações, estruturas condicionais e interação com formulários.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## ✨ Funcionalidades

* Entrada de valor para estacionamento
* Cálculo automático do tempo disponível
* Exibição do resultado na tela
* Validação de valores informados
* Mensagens de aviso para valores insuficientes
* Interface simples e intuitiva

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/brunakm/parquimetro.git
```

2. Abra o arquivo `index.html` em qualquer navegador.
